# CURRENT_TASK (대체됨)

> 이 문서는 **브랜치 저널 체계로 대체**되었다. 더 이상 여기에 slice 로그를 append 하지 않는다.

현재 작업 slice는 자신의 브랜치 저널에 기록한다.

- 위치: `docs/ai/journal/<YYYY-MM-DD>_<branch-slug>.md`
- 새 저널: `node scripts/worklog.js new [slug]`
- 전체 목록: [journal/INDEX.md](journal/INDEX.md)
- 활성 저널이 없을 때: [NEXT_WORK.md](NEXT_WORK.md)
